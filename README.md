# 道の駅 星畑（hoshihata）

> **この道の駅は実在しません。** Web サイト制作のポートフォリオとして制作した架空の施設です。
> 長野県南佐久郡南牧村 野辺山に、この名前の道の駅はありません。

八ヶ岳を見渡すウッドデッキを持つ、架空の道の駅のサイト。

## この作品の主題

架空の施設には**写真が存在しない**。実在地の写真素材で埋めれば実在誤認を招くので、
本作は写真を一切持たず SVG だけで組む。その制約を弱点でなく主題に変えるために、
**絵を描くのではなく、公開データから計算した結果を描く**。

中心は**旬カレンダー** —— 気象庁アメダス野辺山の日別平年値（1991–2020）と
レタスの栽培生理から、「365 日のどの日に何が棚に並ぶか」を導出する。

```
早生の結球レタス   定植 5/11–8/20  →  収穫 6/20 – 9/29
中生の結球レタス   定植 5/11–8/20  →  収穫 6/30 – 10/9
晩生の結球レタス   定植 5/11–8/20  →  収穫 7/10 – 10/12
リーフレタス       定植 4/11–8/10  →  収穫 6/11 – 9/14
```

野辺山は標高 1,350 m、年平均 7.25 ℃、日平均気温が 30 ℃ を超える日は平年値上 0 日。
**冬は何も並ばない。** それを作り物の設定ではなく計算で示すのが、このサイトの背骨である。

## 背骨になっている規律

- **循環の禁止**（SPEC N-02）— モデルのパラメータと検証オラクルを同じ記述から取らない。
  所要日数は原典の本文から、検証は原典の栽培暦と南牧村公式から取る。
  **オラクルの独立性がどこまで残っているかを SPEC §5.3 に明記してある**
- **要約を権威値にしない**（SPEC N-01）— 外部の数値は原典を `data/` に vendor してから採る。
  loop_001 では検索要約が示した数値がモデルの中核になりかけ、原典を開いて否定された
- **落ちることを確かめるまでゲートを信用しない**（SPEC §6）— 架空明示ゲートは、
  実ファイルに違反を注入して赤になることを確認済み。テスト自身にも実証を同梱している（T-04b / T-12b）

## 構成

```
data/            外部の原典（vendor）。data/SOURCE.md が台帳
scripts/         原典 → 生成データの機械変換
src/data/        施設設定・作型定義・生成された平年値
src/lib/         旬カレンダーのモデル
tests/           オラクル検査と架空明示ゲート
SPEC.md          正本。数字を動かすときは先にここを直す
TEST_SPEC.md     テストの期待値と、その出所
logs/loops/      ループログ
```

## 使い方

```bash
npm install
npm run gen        # 原典 HTML → src/data/normals.generated.ts（366 日）
npm test           # テスト 34 件
npm run typecheck
```

## 進み方

L1 完了（旬カレンダーのモデルと架空明示ゲート）。
L2 = ウッドデッキからの八ヶ岳稜線同定図（DEM から方位角・仰角・視通を計算）。
L3 = 直売所・食堂・明暗テーマ。L4 = RV パーク・道のり・お知らせ。L5 = OG・公開。
