# 道の駅 星畑（hoshihata）

> **この道の駅は実在しません。** Web サイト制作のポートフォリオとして制作した架空の施設です。
> 長野県南佐久郡南牧村 野辺山に、この名前の道の駅はありません。

八ヶ岳を見渡すウッドデッキを持つ、架空の道の駅のサイト。

## この作品の主題

架空の施設には**写真が存在しない**。実在地の写真素材で埋めれば実在誤認を招くので、
本作は写真を一切持たず SVG だけで組む。その制約を弱点でなく主題に変えるために、
**絵を描くのではなく、公開データから計算した結果を描く**。

中心は**旬カレンダー** —— 気象庁アメダス野辺山の日別平年値（1991–2020）と
レタスの栽培生理から、「365 日のどの日に何が棚に並ぶか」を導出する。

```
早生の結球レタス   定植 5/11–8/20  →  収穫 6/20 – 9/29
中生の結球レタス   定植 5/11–8/20  →  収穫 6/30 – 10/9
晩生の結球レタス   定植 5/11–8/20  →  収穫 7/10 – 10/12
リーフレタス       定植 4/11–8/10  →  収穫 6/11 – 9/14
```

野辺山は標高 1,350 m、年平均 7.25 ℃、日平均気温が 30 ℃ を超える日は平年値上 0 日。
**冬は何も並ばない。** それを作り物の設定ではなく計算で示すのが、このサイトの背骨である。

もうひとつの柱が**稜線同定図**。国土地理院の標高タイルから射線を飛ばして、
ウッドデッキから見える八ヶ岳の稜線を計算し、峰の名前を当てる。

```
権現岳＜三ッ頭＞ 2580m  方位 266.0°  仰角 7.16°   9.7km   見える
権現岳           2715m  方位 271.0°  仰角 7.66°  10.1km   見える
赤岳             2899m  方位 285.3°  仰角 9.23°   9.5km   見える
横岳             2830m  方位 295.2°  仰角 8.51°   9.8km   見える
硫黄岳           2760m  方位 301.5°  仰角 7.43°  10.7km   見える
天狗岳           2646m  方位 307.0°  仰角 5.59°  13.1km   根石岳あたりの尾根の陰
蓼科山           2531m  方位 317.5°  仰角 2.78°  23.5km   北八ヶ岳の陰
```

方位の窓に入る 13 座のうち**見えるのは 5 座**。
**蓼科山や天狗岳が野辺山から見えない**のは、目で見ただけでは分からない。
図が答えられるのはこの種の問いである。

検証は、**二つの独立な測量 product が同じ山を指すか**で行う ——
稜線は標高メッシュ（等高線由来）だけから、峰の名前と座標は三角点・標高点の測量成果だけから来ている。
実測の方位ずれは最大 **0.15°**。

## 背骨になっている規律

- **循環の禁止**（SPEC N-02）— モデルのパラメータと検証オラクルを同じ記述から取らない。
  所要日数は原典の本文から、検証は原典の栽培暦と南牧村公式から取る。
  **オラクルの独立性がどこまで残っているかを SPEC §5.3 に明記してある**
- **要約を権威値にしない**（SPEC N-01）— 外部の数値は原典を `data/` に vendor してから採る。
  loop_001 では検索要約が示した数値がモデルの中核になりかけ、原典を開いて否定された
- **落ちることを確かめるまでゲートを信用しない**（SPEC §7）— 実ファイルに違反を注入して
  赤になることを確認済み。テスト自身にも実証を同梱している（T-04b / T-12b / T-24）。
  **実証が不発だったら、それは基準が要求を表していない証拠**である —
  名札の重なり検査は当初 `≥ 0` で、押しのけを切っても 1.71 px の隙間で通ってしまった
- **二つの測定系を混ぜて差を取らない** — 判定は片方の系だけで自己完結させ、
  もう一方は照合にだけ使う。混ぜると系統差が判定の余裕に化ける（HC-041）

## 経路

| 経路 | 中身 |
|---|---|
| `/` | 稜線の図・作期の要約 |
| `/shop/` | 旬の帯（通年 366 日）・品 18 点（分類で絞り込み） |
| `/restaurant/` | 品書きと出せる期間・夏と冬の比較 |
| `/panorama/` | 峰の一覧（見える 5 座／隠れる 8 座）・計算方法 |
| `/rv/` | 場内図・電源で何が使えるか・混み具合の見込み |
| `/access/` | 方位盤（地図のピンを持たない代わり）・冬の道 |
| `/news/` | お知らせ 3 件（MDX） |

**「15 A まで」も実際に数えます。** 総当たり 2^7 通りで、冷蔵庫をつけたまま何が足せるかを出します。
冬に要るもの（電気毛布・セラミックヒーター）は気温の平年値から決まります。

**品書きは決め打ちではありません。** その日に棚へ出た野菜から組み立てるので、
8 月 1 日は 7 品、1 月 15 日は 3 品になります。差の 4 品は高原野菜の料理です。

## 構成

```
data/            外部の原典（vendor）。data/SOURCE.md が台帳
scripts/         原典 → 生成データの機械変換・出荷 HTML を読む検査
src/data/        施設設定・作型定義・生成された平年値
src/lib/         旬カレンダーのモデル・稜線同定図の描画
src/app/         ページ（静的書き出し）
src/components/  部品
tests/           オラクル検査と架空明示ゲート
harness/         実ブラウザで図を撮る(目視のための道具)
SPEC.md          正本。数字を動かすときは先にここを直す
TEST_SPEC.md     テストの期待値と、その出所
logs/loops/      ループログ
```

## 使い方

```bash
npm install
npm run gen              # 原典 HTML → 平年値 366 日
npm run gen:terrain      # 標高タイル → 稜線 1401 点 / 峰 13 座
npm test                 # テスト 133 件
npm run typecheck

npm run build            # 静的書き出し（out/）
npm run verify           # 出荷 HTML を読む検査

npm run dev              # 開発サーバ
npm run shot:site        # 出荷サイトを実ブラウザで撮る（--dark で暗色）
npm run render:panorama && npm run shot   # 稜線図だけを撮る
```

**図は目で見る。** 名札の重なりと、方位ラベルが稜線に沈んで読めない不具合は、
どちらもテストが緑のまま通った。SVG の構造としては正しく、DOM 検査も通るからである。

**ただし `file://` で見てはいけない。** 静的書き出しは CSS を絶対パスで参照するので、
`file://` では読み込まれず素の HTML を見ることになる（実際に踏んだ）。
`shot:site` は `out/` を HTTP で配信し、**撮る前に色トークンが空でないことを確かめる**。
